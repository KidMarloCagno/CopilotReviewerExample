# Sistema de Gestión de Hotel CLI

Un programa de línea de comandos desarrollado en Java para gestionar las operaciones básicas de un hotel.

## Características

- Listar habitaciones disponibles
- Crear habitación
- Calcular precio de reservación
- Realizar reservación

## Archivos

- `Room.java`
- `Reservation.java`
- `HotelManager.java`
- `Main.java`
